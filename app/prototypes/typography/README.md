# Typography

Live text input with two CSS-only display styles: calm and chaotic.

## How to run

From the project root:

```bash
npm run dev
```

Open [http://localhost:3000/prototypes/typography](http://localhost:3000/prototypes/typography).

## Build phases

| Phase | Style | Status |
|-------|-------|--------|
| 0 | Scaffold (shell, input, tabs) | Done |
| 1 | Calm — ocean waves, soft blues, grain | Done |
| 2 | Chaotic — random color/font per word | Done |

## Stack

- Next.js (App Router)
- React client component
- CSS Modules (one file per style when built)
