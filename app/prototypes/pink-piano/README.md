# PinkSynth™

A digital piano / synthesizer prototype styled like classic Mac OS (System 7), in a monochromatic pink palette.

## Features

- Playable piano keyboard (mouse / touch)
- Computer keyboard shortcuts (A–K for white keys, W E T Y U for black keys)
- Waveform select: sine, square, sawtooth, triangle
- Octave shift (−2 to +2)
- Waveform, octave, and volume controls
- Play a Tune panel (Für Elise demo with key highlight)
- Web Audio API synthesis (no external audio files)

## How to run

From the project root:

```bash
npm run dev
```

Open [http://localhost:3000/prototypes/pink-piano](http://localhost:3000/prototypes/pink-piano).

## Stack

- Next.js (App Router)
- React client component
- CSS Modules
- Web Audio API
